# POLARITY

Игра в одно касание про магниты. Чистый HTML/CSS/JS, без бэкенда и сборки.

- **Тап / пробел** — меняет твой заряд (+ / −).
- Разные заряды притягиваются, одинаковые отталкиваются.
- Собирай кристаллы (комбо до ×10), избегай мин, не отставай от экрана.
- **Ежедневный вызов** — один и тот же уровень для всех в течение дня.

## Запуск на GitHub Pages

1. Залей файлы в репозиторий на GitHub.
2. Settings → Pages → Source: `main` / root → Save.
3. Через минуту игра будет доступна по адресу `https://<user>.github.io/<repo>/`.

Локально: открой `index.html` в браузере.
